# Staffline — Team management

View employee details, manage your roster, and create follow-up tasks.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Features

- Sample roster with managers and direct reports (fictional data)
- Add / edit people, assign managers, filter by department
- Team overview by department with open-task counts
- Create / complete tasks tied to an employee

Tasks and edits are stored in component state (not persisted).
